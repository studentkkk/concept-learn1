## 单元 1 · Python 运行环境

### 课程 1.1 什么是 Python 与解释器

- **知识点 1.1.1** Python 是一门解释型、动态类型的高级编程语言
- **知识点 1.1.2** 解释器（interpreter）的作用：逐行读取源码并执行
- **知识点 1.1.3** CPython 是官方参考实现，也是最常用的实现
- **知识点 1.1.4** 解释型与编译型语言的差异（无独立编译产物）
- **知识点 1.1.5** 源代码文件的后缀名 `.py`

### 课程 1.2 Python 的安装与版本管理

- **知识点 1.2.1** 从 python.org 下载官方安装包
- **知识点 1.2.2** 安装时勾选 "Add Python to PATH" 的作用与后果
- **知识点 1.2.3** 用 `python --version` / `python3 --version` 检查版本
- **知识点 1.2.4** Python 2 与 Python 3 的区别（本课程只用 Python 3）
- **知识点 1.2.5** 虚拟环境的用途；`venv` 的创建与激活
- **知识点 1.2.6** 多版本共存时的路径冲突排查思路

### 课程 1.3 命令行与运行第一个程序

- **知识点 1.3.1** 终端的打开方式（Windows / macOS / Linux）
- **知识点 1.3.2** 当前工作目录（cwd）的概念
- **知识点 1.3.3** `cd`、`ls`/`dir`、`pwd` 等基础命令
- **知识点 1.3.4** 用 `python script.py` 运行脚本文件
- **知识点 1.3.5** 交互式 REPL：直接输入 `python` 进入
- **知识点 1.3.6** `print()` 输出第一个 "Hello, Python"
- **知识点 1.3.7** 退出 REPL：`exit()` 或 `Ctrl+D` / `Ctrl+Z`

### 课程 1.4 包管理与第三方库

- **知识点 1.4.1** pip 是什么，以及它与 Python 的关系
- **知识点 1.4.2** `pip install <包名>` 安装第三方包
- **知识点 1.4.3** `pip list`、`pip show` 查看已安装包
- **知识点 1.4.4** `pip uninstall` 卸载包
- **知识点 1.4.5** `import` 语句的基本用法
- **知识点 1.4.6** 包安装到了错误环境（全局 / 虚拟环境）的常见症状

### 课程 1.5 编辑器与开发工具的初识

- **知识点 1.5.1** 文本编辑器、IDE、笔记本三者的区别
- **知识点 1.5.2** VS Code 的基本配置（解释器选择、Python 扩展）
- **知识点 1.5.3** PyCharm 的项目解释器概念
- **知识点 1.5.4** 语法高亮与自动补全的作用
- **知识点 1.5.5** 为什么需要统一保存为 UTF-8 编码

## 单元 2 · Notebook 与内核

### 课程 2.1 认识 Jupyter Notebook

- **知识点 2.1.1** Notebook 是什么：代码 + 文本 + 输出的混合文档
- **知识点 2.1.2** `.ipynb` 文件本质是 JSON 格式
- **知识点 2.1.3** Jupyter Notebook 与 JupyterLab 的差异
- **知识点 2.1.4** VS Code / WPS 等编辑器内置 Notebook 体验
- **知识点 2.1.5** 单元格（cell）的概念与构成

### 课程 2.2 单元格的类型

- **知识点 2.2.1** Code cell 与 Markdown cell 的区别
- **知识点 2.2.2** 单元格的插入、删除、移动、复制
- **知识点 2.2.3** Markdown 语法基础：标题、加粗、列表、行内代码
- **知识点 2.2.4** 代码块的书写方式
- **知识点 2.2.5** 单元格上下移动的快捷键

### 课程 2.3 执行顺序与状态

- **知识点 2.3.1** 单元格靠 `Shift+Enter` / `Ctrl+Enter` 执行
- **知识点 2.3.2** 执行编号 `In [ ]` 的含义
- **知识点 2.3.3** 执行顺序不等于书写顺序（乱序执行的坑）
- **知识点 2.3.4** 变量在 notebook 全局内存中共享
- **知识点 2.3.5** 为什么需要"Restart & Run All"来验证结果
- **知识点 2.3.6** 输出区的历史输出不会随代码修改自动清除

### 课程 2.4 内核（Kernel）

- **知识点 2.4.1** 内核是什么：真正执行代码的后台进程
- **知识点 2.4.2** 内核的生命周期与内存状态
- **知识点 2.4.3** Restart Kernel 与 Interrupt Kernel 的区别
- **知识点 2.4.4** 内核挂死（长时间运行、死循环）的表现与处理
- **知识点 2.4.5** 切换 / 选择 Python 内核与虚拟环境
- **知识点 2.4.6** 内核崩溃后 notebook 的表现

### 课程 2.5 输出与显示

- **知识点 2.5.1** 单元格自动显示最后一个表达式的值
- **知识点 2.5.2** `print()` 与"表达式自动回显"的区别
- **知识点 2.5.3** 输出过长时的截断与滚动
- **知识点 2.5.4** 富文本输出：图片、表格、HTML 的内联显示
- **知识点 2.5.5** 输出被清除与重新执行的时机

### 课程 2.6 Notebook 的实用操作

- **知识点 2.6.1** 常用快捷键（执行、插入、切换类型、保存）
- **知识点 2.6.2** 命令模式与编辑模式的区别
- **知识点 2.6.3** 保存、导出为 `.py` / `.html` / `.pdf`
- **知识点 2.6.4** 单元格执行的独立性：互不依赖、共享内存
- **知识点 2.6.5** 清理输出后提交 notebook 的良好习惯

## 单元 3 · 报错与 Traceback

### 课程 3.1 认识报错信息

- **知识点 3.1.1** 报错不是失败，而是定位问题的线索
- **知识点 3.1.2** 报错的三个部分：类型、描述、位置
- **知识点 3.1.3** 错误信息阅读顺序：从最后一行开始
- **知识点 3.1.4** 报错信息中的文件名与行号
- **知识点 3.1.5** 报错信息中的 `^` 指向符号

### 课程 3.2 Traceback 的结构

- **知识点 3.2.1** Traceback 的字面含义："调用栈的追溯"
- **知识点 3.2.2** 自上而下的调用层级排列
- **知识点 3.2.3** `File "...", line N, in <module>` 的读法
- **知识点 3.2.4** 多层函数调用时的 Traceback 展开
- **知识点 3.2.5** 最后一行的错误类型与错误消息
- **知识点 3.2.6** 如何从 Traceback 定位"真正出错的那一行"

### 课程 3.3 常见错误类型（上）

- **知识点 3.3.1** `SyntaxError`：语法错误，代码无法被解析
- **知识点 3.3.2** `IndentationError`：缩进错误
- **知识点 3.3.3** `NameError`：使用了未定义的名称
- **知识点 3.3.4** `TypeError`：类型不匹配（如数字与字符串相加）
- **知识点 3.3.5** `ValueError`：类型正确但取值不合法
- **知识点 3.3.6** 如何根据错误类型名快速缩小排查范围

### 课程 3.4 常见错误类型（下）

- **知识点 3.4.1** `IndexError`：索引越界
- **知识点 3.4.2** `KeyError`：字典键不存在
- **知识点 3.4.3** `AttributeError`：对象没有该属性或方法
- **知识点 3.4.4** `ImportError` / `ModuleNotFoundError`：模块找不到
- **知识点 3.4.5** `ZeroDivisionError`：除以零
- **知识点 3.4.6** `FileNotFoundError`：文件路径不存在

### 课程 3.5 错误排查方法论

- **知识点 3.5.1** 从下往上读 Traceback 的固定流程
- **知识点 3.5.2** 复制完整报错信息（含 Traceback）去搜索
- **知识点 3.5.3** 二分法定位：逐步注释 / 删除代码
- **知识点 3.5.4** 用 `print()` 打印中间变量做检查
- **知识点 3.5.5** 一次只改一个问题
- **知识点 3.5.6** Notebook 中"旧结果残留"导致的假象排查

### 课程 3.6 主动处理错误

- **知识点 3.6.1** `try` / `except` 的基本结构
- **知识点 3.6.2** 捕获指定异常类型
- **知识点 3.6.3** `else` 与 `finally` 的作用
- **知识点 3.6.4** `raise` 主动抛出异常
- **知识点 3.6.5** 为什么不要用裸 `except:` 吞掉所有错误
- **知识点 3.6.6** 读取错误信息文本：`str(e)` 与 `repr(e)`

## 单元 4 · 变量与基本类型

### 课程 4.1 变量与赋值

- **知识点 4.1.1** 变量是"名字到值的引用"
- **知识点 4.1.2** 赋值语句 `=` 的含义（不是数学等号）
- **知识点 4.1.3** 变量命名规则（字母、数字、下划线，不能数字开头）
- **知识点 4.1.4** 命名惯例：小写 + 下划线（snake_case）
- **知识点 4.1.5** Python 关键字不能用作变量名
- **知识点 4.1.6** 用 `type()` 查看变量类型
- **知识点 4.1.7** 动态类型：变量可重新绑定到不同类型的值

### 课程 4.2 数字类型

- **知识点 4.2.1** `int` 整数类型（无大小上限）
- **知识点 4.2.2** `float` 浮点数类型
- **知识点 4.2.3** `complex` 复数类型（了解）
- **知识点 4.2.4** 算术运算符：`+ - * / // % **`
- **知识点 4.2.5** 整除 `//` 与取余 `%` 的用法
- **知识点 4.2.6** 浮点数精度问题（如 `0.1 + 0.2`）
- **知识点 4.2.7** 类型转换：`int()`、`float()`、`round()`

### 课程 4.3 布尔类型

- **知识点 4.3.1** `bool` 只有 `True` 与 `False`
- **知识点 4.3.2** 比较运算符：`== != > < >= <=`
- **知识点 4.3.3** 逻辑运算符：`and`、`or`、`not`
- **知识点 4.3.4** 真值判断：哪些值被视为假（`0`、`""`、`[]`、`None`）
- **知识点 4.3.5** 布尔值的运算特性（短路求值）
- **知识点 4.3.6** `bool` 是 `int` 的子类（`True == 1`）

### 课程 4.4 字符串类型

- **知识点 4.4.1** 字符串的三种引号写法（单引号、双引号、三引号）
- **知识点 4.4.2** 转义字符：`\n`、`\t`、`\\`
- **知识点 4.4.3** 字符串拼接与重复（`+`、`*`）
- **知识点 4.4.4** 索引与切片：`s[0]`、`s[1:3]`、`s[::-1]`
- **知识点 4.4.5** 常用方法：`upper()`、`lower()`、`strip()`、`replace()`、`split()`
- **知识点 4.4.6** `len()` 获取长度
- **知识点 4.4.7** 字符串格式化：f-string、`format()`、`%`
- **知识点 4.4.8** 字符串不可变（immutable）的含义

### 课程 4.5 空值与类型转换

- **知识点 4.5.1** `None` 表示"没有值"
- **知识点 4.5.2** `None` 与 `0`、`""`、`False` 的区别
- **知识点 4.5.3** 用 `is None` 判断空值
- **知识点 4.5.4** 显式类型转换：`int()`、`float()`、`str()`、`bool()`
- **知识点 4.5.5** 隐式转换与显式转换的区别
- **知识点 4.5.6** 转换失败的典型报错（`ValueError`）

### 课程 4.6 输入输出与综合练习

- **知识点 4.6.1** 用 `print()` 输出，多个参数与 `sep`、`end`
- **知识点 4.6.2** 用 `input()` 获取用户输入（返回值永远是字符串）
- **知识点 4.6.3** 输入后必须显式转换为数字类型
- **知识点 4.6.4** 注释的写法：`#` 与文档字符串
- **知识点 4.6.5** 综合练习：温度转换小程序
- **知识点 4.6.6** 综合练习：输入两个数并输出四则运算结果
